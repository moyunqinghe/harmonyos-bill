# Bill 内页重设计与验收（2026-09-06）

## 实现

- 首页、账单、月报三标签；固定记账入口。首页展示本月个人花销、消费原额、已到账报销、所有月份待报销、收入、还款和最近五笔。
- 账单默认全部时间，支持支出、收入、还款／转账及跨月待报销筛选。保留滑动删除及二次确认。
- 分类和支付方式通过底部面板点选、自动收起，可清除；新记录不继承上一笔。话费默认待报销，手动勾选与分类自动勾选分别处理。备注、凭证折叠。
- 报销页优先全额确认、允许调整日期，部分到账和更正在次级入口。全额写入累计原消费金额。
- 月报复用 MonthlyReport：分类按个人花销，支付按原消费金额；固定浅色渐变、每日趋势、收入与还款汇总。所选月份传入 PDF 预览，全部 CSV 在账单页导出。
- 修复 ArkUI Builder 值参数导致的分类文字、月份图表刷新滞后；首页/月报内容按新数据更新，标签、筛选与月份保留。
- 系统键盘使用 RESIZE 避让，保存按钮可获取焦点，完成输入后恢复数字键盘。浅色与深色资源自动适配。

## 数据边界

正式数据库仍为 `bill.db`。本轮内页改造不改数据库结构、金额、备注、分类、支付、凭证或报销存储。所有新增、修改、删除及报销的真机测试在独立 `bill_redesign_20260906.db` 中进行。测试包临时改库名和首页标题，构建后使用 finally 恢复源码。覆盖安装使用 `hdc install -r`，不卸载、不清除应用数据。

## 旧提醒清理的实机兼容处理

最终源码移除提醒卡片、发布调度、通知授权请求及 `PUBLISH_AGENT_REMINDER` 声明，只保留启动清理与失败重试。

本机实际系统与本地 SDK 注释存在差异：移除权限后，`cancelAllReminders` 和 `getValidReminders` 均返回201（Permission denied）。因此此次安装先使用仅包含取消逻辑、暂留原权限的过渡包，完成取消及旧配置清理；实机显示「旧提醒 0 · 清理完成 true · 旧开关 false」，重启仍为零。再覆盖无提醒权限的正式包。过渡包不发布提醒、不请求通知授权。

若将最终包直接升级到另一台尚未清理提醒、且同样限制取消接口的旧设备，也需要先完成这一过渡清理；失败不会伪报完成，清理标记不落盘，下次启动重试，不阻塞账本。不能仅凭无权限包的单元测试断言任意旧设备均已完成清理。
