# 常用场景与支付按钮

## 使用方式

- 支出直接点选「购物、交通、餐饮、话费、居住缴费、休闲娱乐、医疗健康、人情往来、其他」和「零钱、信用卡、花呗、白条、美团月付、抖音月付」，输入金额即可保存，不要求填写备注。
- 两组选择都是可选的；再次点击已选按钮即可取消。未选不会自动推断或沿用上一笔，避免误记支付方式。
- 话费默认待报销，实际到账后再登记全额到账；改选其他场景会取消本次自动勾选的待报销，手动设置的待报销保留。
- 支出、收入、还款、转账均在录入页直接点选。平台欠款统一记还款，不必指定平台，不重复计入花销。
- 补充说明和图片在表单下方，可滚动访问；数字键盘与保存按钮固定在下方。
- 账单列表展示场景、支付方式和报销状态。不填备注时，用场景作为标题。
- CSV 保留原先八列，末尾新增「消费场景」「支付方式」。本次未增加图表报表导出。

## 数据兼容

正式库仍为 `bill.db`。新增 `bill_details` 关联表，保存可选场景和支付方式，不重写旧账单、原备注、金额、凭证或报销信息。旧记录显示未选择，用户可自行编辑补充。新增、编辑、删除与报销及明细字段在同一事务内完成。改为收入、还款或转账后移除消费专属字段。
