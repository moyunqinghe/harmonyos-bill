# 启动过渡：生活小账页

系统启动屏使用三条小巧的浅色账页标记，替换原来占据中心的大图标；桌面应用图标保持原样。冷启动加载 LaunchPage，日常消费、平台还款、话费报销三张浅色渐变卡片依次出现，呼应本应用的记账规则。

主文案为「记下生活，算清自己的花销。」启动过渡不读取或展示个人金额。约 1.1 秒后用 replaceUrl 进入首页；可点「进入账本」或返回键跳过。离页清理计时器，路由失败可重试。返回首页、正常后台恢复不会重新创建启动页。

验证：DevEco 签名构建通过；USB 真机冷启动自动到达首页、点击跳过到达首页、账单页返回首页不重播，均通过。新版已覆盖安装，未对原账单执行任何写入。
